# کادوی تولد مانی

این پروژه یک Telegram Mini App تک صفحه ای و مناسب موبایل است

## فایل های لازم

- index.html
- style.css
- script.js
- aksmani.PNG
- ahangmani.MP3

عکس و آهنگ را دقیقا با همین نام در ریشه پروژه قرار بده

## اجرای محلی

فایل ها را روی یک وب سرور ساده اجرا کن

برای مثال با VS Code و Live Server

## انتشار با GitHub Pages

در Repository گیت هاب برو به

Settings

Pages

Source را روی Deploy from a branch بگذار

Branch را روی main و پوشه را روی root قرار بده

بعد از انتشار آدرس GitHub Pages را به عنوان Web App ربات تلگرام استفاده کن

## اتصال به Telegram Bot

در BotFather برای ربات خودت یک Web App یا Menu Button بساز و آدرس GitHub Pages را به آن بده

برای تست سریع هم می توانی لینک GitHub Pages را داخل چت ربات باز کنی

## نکته

پخش خودکار صدا در مرورگرها محدود است

در این پروژه صدا با زدن دکمه صفحه آخر پخش می شود
